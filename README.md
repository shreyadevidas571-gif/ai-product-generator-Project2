# AI Product Generator

An AI-powered web application that generates product descriptions using **Google Gemini AI** and **Streamlit**.

## 🚀 Features

- Generate AI-powered product descriptions
- Simple and interactive chat interface
- Built with Streamlit
- Powered by Google Gemini API

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API

## 📁 Project Structure

```
AI-Product-Generator/
│── app.py
│── requirements.txt
│── README.md
│── .gitignore
└── .streamlit/
```

## 📦 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/ai-product-generator.git
```

2. Navigate to the project folder

```bash
cd ai-product-generator
```

3. Install the required packages

```bash
pip install -r requirements.txt
```

## 🔑 Configure API Key

Create a `.streamlit/secrets.toml` file and add your Google Gemini API key:

```toml
GOOGLE_API_KEY = "YOUR_API_KEY"
```

> **Do not commit your API key to GitHub.**

## ▶️ Run the Application

```bash
streamlit run app.py
```

The application will open in your browser.

## 💡 Example

**Input:**

```
A reusable stainless steel water bottle for travelers.
```

**Output:**

An AI-generated product description highlighting the bottle's durability, portability, and eco-friendly design.
